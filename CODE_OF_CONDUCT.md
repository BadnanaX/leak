# Code of Conduct

## Our standard

We want LEAK to be a welcoming, constructive project. Be respectful, assume good faith, and focus criticism on ideas and code rather than people.

Examples of behavior that helps include:

- Giving clear, considerate feedback.
- Accepting corrections gracefully.
- Explaining disagreements without personal attacks.
- Respecting privacy and not publishing another person's scan results or identifying information without permission.

Unacceptable behavior includes harassment, insults, discrimination, deliberate intimidation, and sharing private information without consent.

## Scope

This standard applies in project issues, pull requests, discussions, and other spaces where someone is representing the project.

## Reporting

If someone behaves in a way that violates this standard, contact the project maintainer privately through the contact method listed on their GitHub profile. Please do not post private or sensitive details in a public issue.

The maintainer will review reports fairly and may edit or remove inappropriate content, close discussions, or restrict participation when necessary.
