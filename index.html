What actually helps

Browser protections change over time and may vary by version. Review the current settings and documentation for your browser.

FirefoxEnhanced Tracking Protection set to Strict can block more trackers. The advanced privacy.resistFingerprinting preference may change exposed signals but can break sites; check current Firefox documentation before changing advanced settings.
BraveShields includes fingerprinting protections. Exact behavior varies by version and settings; some protections may alter or standardize readings.
SafariSafari includes tracking and fingerprinting protections whose availability depends on OS version, browsing mode, and settings. Review the current Privacy settings.
Chrome / EdgeReview privacy and site permissions, remove extensions you do not trust, and keep the browser updated. Available anti-tracking controls differ by version.
Any browserA VPN changes the network address a site sees, not most browser readings. Tracker blocking and limiting unnecessary extensions can reduce exposure, but do not guarantee fingerprint resistance.

What the scan does and does not do

When you start a scan, LEAK reads browser APIs and runs small rendering tests. It checks whether cookies are enabled but never reads cookies. It does not access passwords, local files, or GPS.

It does not open a WebRTC connection. It only checks whether the API exists.

The scan code does not intentionally set cookies, write browser storage, or send scan results to a server. Your hosting provider, browser, extensions, or network may still process ordinary connection metadata.

The optional IP lookup contacts ipwho.is after you confirm. That service receives your request and can see your public IP; review its current privacy policy before using the lookup.
